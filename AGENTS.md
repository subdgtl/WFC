# Repository instructions

## Independent delivery

When the owner starts the new delivery method, use `.agents/skills/independent-delivery/SKILL.md`. It supports both cloud providers, one persisted 300-second allowance for all required automated integration checks, and complete verification on a separate machine while implementation continues. Preserve existing product, approval and deployment rules. Adding this procedure does not change a running controller or start delivery.
